# quines

A collection of quines I wrote.

A quine is a computer program which prints its own source code. `C++.cpp`, `MATLAB.m`, and `Python.py` are quines.

A cross-language quine is a computer program written in one language, which outputs the source code for a computer program written in another language, which itself outputs the source code for the original program written in the first language. 

`MATLABPython.m` is a MATLAB -> Python cross-language quine, and `PythonMATLAB.py` is the Python -> MATLAB cross-language quine which `MATLABPython.m` outputs.
